# Spirit Client (Confis + Spirit in ONE jar)

Build on GitHub (no setup on your PC):
1. Create a GitHub repo, upload ALL files/folders from this project (keep the .github folder).
2. Open the "Actions" tab -> "Build Spirit Client" -> wait for the green check.
3. Open the run -> "Artifacts" -> download SpiritClient-jar -> unzip -> put the .jar in .minecraft/mods.

Keys: Right Shift = menu, C = zoom, F6 = freecam, H = inventory hub.
If the build is red, open the failed step and send me the red error text; I will fix the code.
